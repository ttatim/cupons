## Instalação inicial limpa (não é migração de banco existente)

1. Providencie PHP 8.3 ou 8.4 com extensões `pdo_mysql`, `curl`, `dom`, `fileinfo`, `json`, `mbstring`, `openssl` e `gd` para upload legado; MySQL 8.0+; servidor HTTPS Apache/Nginx com PHP-FPM. Não são necessários Node.js, Next.js, TypeScript, Composer ou build frontend nesta entrega.
2. Crie **um banco completamente vazio** em `utf8mb4` e usuário SQL exclusivo com permissões de criação/alteração de tabelas durante a instalação. Faça isso somente em banco novo. Não aponte para produção existente.
3. Configure fora do webroot, por mecanismo de segredos do servidor, `APP_ENV=production`, `DB_HOST`, `DB_NAME`, `DB_USER` e `DB_PASS`. Nunca grave senhas ou tokens no Git, logs, shell history ou documentos.
4. Execute `php scripts/check_runtime.php`. Se falhar, corrija o runtime antes de instalar.
5. Com essas variáveis já exportadas para o processo CLI, execute `INSTALL_CLEAN_CONFIRM=EMPTY_DATABASE_ONLY php scripts/install_clean.php`. O instalador **recusa bancos que já possuam tabelas**, inicializa as tabelas base e aplica, na ordem, as nove migrações versionadas em `sql/updates/`. Ele **não insere usuários, produtos, cupons, lojas, eventos ou credenciais**. Se houver erro após iniciar DDL, **não repita** no mesmo banco: diagnostique e use outro banco vazio. MySQL DDL não garante rollback transacional.
6. Crie explicitamente a primeira conta administrativa usando `ADMIN_USERNAME`, `ADMIN_EMAIL` e `ADMIN_PASSWORD` (mínimo 16 caracteres) via `php scripts/create_admin.php`, com segredo fornecido por mecanismo seguro.
7. Acesse `/admin/login.php`, crie uma loja e depois cadastre produtos/cupons ou utilize a importação assistida. Nenhum dado de demonstração é necessário.
8. Configure HTTPS, backups, privilégios mínimos e bloqueie o acesso HTTP a `includes/`, `scripts/`, `sql/`, `tests/`, `logs/`, configurações e backups. Proteja `assets/uploads/` contra execução de scripts. Não exponha `.env`.
9. **Não importe** `sql/database.sql` (schema legado incompleto para esta versão) nem `sql/sample-database.sql` (dados de demonstração). **Não execute testes que inserem dados** em produção.

## Arquivos e schema

- `scripts/install_clean.php`: instalação inicial com recusa de banco não vazio, sem limpeza nem seed.
- `includes/database.php`: bootstrap das tabelas base.
- `sql/updates/*.sql`: nove migrações incrementais (staging de produtos e comissões, relay e revisão Monetizze).
- `.github/workflows/clean-install-release.yml`: teste de instalação em MySQL 8.0 + PHP 8.3/8.4, recusa de reinstalação e smoke da vitrine com dados **sintéticos apenas no banco descartável do CI**.
- `.github/workflows/item-01-php.yml`: análise sintática, testes e smoke legados.
- `.github/workflows/affiliate-staging.yml`: integração MySQL de componentes de staging.
